# Sound Files

This directory should contain the following 8-bit sound effects:

## Required Files:

### click.mp3
A short 8-bit click/blip sound for button interactions.
Recommended: ~100ms duration

### success.mp3  
An 8-bit success/achievement sound for form submission.
Recommended: ~500ms duration

### konami.mp3
A special 8-bit fanfare for the Konami code easter egg.
Recommended: ~1-2 seconds duration

## Where to find free 8-bit sounds:

1. **Freesound.org** - Search for "8-bit click" or "retro game sound"
2. **OpenGameArt.org** - Free game audio assets
3. **BFXR** (bfxr.net) - Generate your own 8-bit sounds!

## Note:
Make sure to use royalty-free sounds or sounds you have the rights to use.
