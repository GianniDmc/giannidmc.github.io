# Polices style Seigneur des Anneaux

Ce dossier doit contenir les polices LOTR pour un rendu optimal.

## Polices à télécharger :

### Aniron (recommandée)
Police inspirée des titres du Seigneur des Anneaux.
- Téléchargement : https://www.dafont.com/aniron.font
- Fichier : `aniron.ttf`

### Ringbearer (alternative)
Police elfique du Seigneur des Anneaux.
- Téléchargement : https://www.dafont.com/ringbearer.font
- Fichier : `ringbearer.ttf`

## Installation :
1. Téléchargez les fichiers `.ttf`
2. Placez-les dans ce dossier (`public/fonts/`)
3. Le CSS les chargera automatiquement

## Fallback :
Si les polices ne sont pas disponibles, le site utilisera `Cinzel Decorative` de Google Fonts (déjà inclus).
