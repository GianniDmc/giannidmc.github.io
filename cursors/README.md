# Cursor Files

This directory should contain the custom cursor for the site.

## Required File:

### sword-cursor.png
A PNG image of Geralt's sword or a medieval sword cursor.

**Recommended specifications:**
- Size: 32x32 pixels (for best compatibility)
- Format: PNG with transparency
- Hot spot: Top-left corner (0, 0)

## Alternative: Use a .cur file
You can also use a proper cursor file (.cur) which allows you to set the hotspot precisely.

## How to create:
1. Find or create a sword image
2. Resize to 32x32 pixels
3. Rotate if needed so the tip points to top-left
4. Export as PNG with transparent background

## Fallback:
If no custom cursor is found, the site will use the default pointer cursor.
